# CV Lab 6 - Intensity Slicing

## Aim
Perform intensity slicing on a grayscale image with and without preserving the background.

## Experiment
The notebook uses the intensity range:
- Minimum intensity: 100
- Maximum intensity: 200

Pixels whose intensity lies within this range are highlighted.

Two results are produced:
1. Intensity slicing without background
2. Intensity slicing with background

## Output
- Original grayscale image
- Sliced image without background
- Sliced image with background

## Requirements
Install the libraries in `requirements.txt`.

## Run
Open `Cvlab6.ipynb` in Jupyter Notebook, JupyterLab, or Google Colab and run the cells in order.
